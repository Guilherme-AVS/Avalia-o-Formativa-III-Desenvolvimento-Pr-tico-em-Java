# Aula 13 — Classes Abstratas em Java

Material completo da Aula 13/23 — 2026.2.

## Foco
Classes abstratas, métodos abstratos e concretos, estado compartilhado, construtores, `super()`, `@Override`, polimorfismo, coesão, acoplamento, `final` e comparação com interfaces.

## Estrutura
`apoio/` conceitos | `exemplos/` código executável | `exercicios/` prática | `desafios/` projetos | `gabaritos/` soluções | `uml/` Draw.io editável | `docs/` planejamento.

## Regra central
Uma classe abstrata representa uma base coerente que não deve ser instanciada diretamente. Ela pode compartilhar estado e implementação e pode exigir comportamentos por meio de métodos abstratos.

## Execução
Em cada exemplo com `Main.java`: `javac *.java` e `java Main`.
