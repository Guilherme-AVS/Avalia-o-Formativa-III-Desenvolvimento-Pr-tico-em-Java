# Aula 14 — Interfaces em Java


## Objetivos
- compreender interface como contrato de comportamento;
- declarar e implementar interfaces com `implements`;
- usar `@Override`, métodos `default` e `static`;
- implementar múltiplas interfaces;
- aplicar polimorfismo por referência de interface;
- decidir entre interface e classe abstrata;
- projetar sistemas com baixo acoplamento e alta coesão;
- reconhecer ISP/DIP em exemplos introdutórios.

## Estrutura
- `apoio/`: material conceitual e metodológico;
- `exemplos/`: exemplos executáveis;
- `exercicios/`: atividades com código-base funcional;
- `desafios/`: problemas de maior autonomia;
- `gabaritos/`: soluções de referência;
- `uml/`: diagramas editáveis Draw.io;
- `docs/`: roteiro, rubricas e conexão curricular.

**Pré-requisitos:** Aulas 11–13 — herança, polimorfismo e classes abstratas.

**Regra pedagógica:** primeiro modele o contrato; depois escolha implementações concretas.
