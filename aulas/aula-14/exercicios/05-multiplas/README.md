# Exercício 5 — 05 Multiplas

## Enunciado
Faça uma classe implementar dois contratos independentes e use cada referência pelo contrato apropriado.

## Critérios
- contrato bem definido;
- implementação correta;
- `@Override`;
- uso do tipo da interface;
- ausência de casts desnecessários;
- código compilável.

## Entrega
Inclua UML em Draw.io, código Java e uma breve justificativa de design.
