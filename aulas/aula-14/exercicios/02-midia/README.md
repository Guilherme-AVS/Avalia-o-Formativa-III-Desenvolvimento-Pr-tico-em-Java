# Exercício 2 — 02 Midia

## Enunciado
Modele mídia reproduzível. Diferencie o que é comum por contrato e o que é específico por implementação.

## Critérios
- contrato bem definido;
- implementação correta;
- `@Override`;
- uso do tipo da interface;
- ausência de casts desnecessários;
- código compilável.

## Entrega
Inclua UML em Draw.io, código Java e uma breve justificativa de design.
