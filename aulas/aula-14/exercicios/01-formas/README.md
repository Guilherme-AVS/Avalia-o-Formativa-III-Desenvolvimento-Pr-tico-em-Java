# Exercício 1 — 01 Formas

## Enunciado
Crie/complete um sistema de formas com área e perímetro. Use uma coleção `List<Calculavel>` para demonstrar polimorfismo.

## Critérios
- contrato bem definido;
- implementação correta;
- `@Override`;
- uso do tipo da interface;
- ausência de casts desnecessários;
- código compilável.

## Entrega
Inclua UML em Draw.io, código Java e uma breve justificativa de design.
