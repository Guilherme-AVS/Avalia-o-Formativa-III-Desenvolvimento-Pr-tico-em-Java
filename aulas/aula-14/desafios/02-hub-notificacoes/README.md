# Desafio 2 — Hub de notificações

## Problema
Combine `Notificavel`, `Prioritario` e uma coleção polimórfica. Adicione uma nova implementação sem alterar o serviço.

## Restrições
- não use `instanceof` no código cliente;
- programe para interfaces;
- aplique baixo acoplamento;
- entregue UML editável;
- adicione pelo menos uma implementação nova sem modificar o serviço principal.

## Rubrica
Contrato 2,0 · implementação 2,0 · polimorfismo 2,0 · design 2,0 · UML 1,0 · justificativa 1,0.
