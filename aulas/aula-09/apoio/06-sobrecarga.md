# Sobrecarga de construtores

Uma classe pode ter vários construtores, desde que suas assinaturas sejam diferentes.

Exemplo conceitual:
- `Produto()`
- `Produto(String nome)`
- `Produto(String nome, double preco)`
- `Produto(String nome, double preco, String marca)`

A sobrecarga oferece diferentes formas de criação sem exigir classes diferentes.
