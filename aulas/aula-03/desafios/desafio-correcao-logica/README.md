# Desafio — Corrija a lógica

Crie uma versão com erros intencionais de uma estrutura condicional e peça a outro colega para localizar os problemas.

Verifique especialmente:
- ordem das condições;
- limites das faixas;
- uso de `&&` e `||`;
- `break` em `switch`;
- caminho `default`;
- condições que nunca são alcançadas.
