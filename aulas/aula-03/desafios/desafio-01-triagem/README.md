# Desafio 01 — Sistema de Triagem

Crie um sistema que classifique a prioridade de atendimento com base em sintomas e idade, com pelo menos três níveis de urgência.

Antes do Java:
1. escreva as regras;
2. desenhe o fluxograma;
3. identifique casos especiais;
4. implemente;
5. teste diferentes cenários.
