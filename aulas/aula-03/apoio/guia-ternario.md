# Operador ternário

Sintaxe:

```java
resultado = (condicao) ? valorSeVerdadeiro : valorSeFalso;
```

Exemplos:

```java
String tipo = (numero % 2 == 0) ? "Par" : "Ímpar";
int maior = (a > b) ? a : b;
String status = (idade >= 18) ? "Maior" : "Menor";
```

Use o ternário para expressões simples. Evite ternários aninhados.
