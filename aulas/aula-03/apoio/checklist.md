# Checklist da Aula 03

- [ ] Sei explicar o que é uma estrutura condicional.
- [ ] Sei escrever um `if`.
- [ ] Sei diferenciar `if` de `if-else`.
- [ ] Sei encadear `else if`.
- [ ] Sei explicar por que a ordem das condições importa.
- [ ] Sei usar `switch-case`.
- [ ] Sei explicar o papel do `break`.
- [ ] Sei usar `default`.
- [ ] Sei escolher entre `if` e `switch`.
- [ ] Sei ler um fluxograma de decisão.
- [ ] Sei transformar uma decisão de fluxograma em Java.
- [ ] Sei usar o operador ternário em situações simples.
