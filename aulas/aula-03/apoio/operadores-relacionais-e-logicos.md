# Operadores relacionais e lógicos

## Relacionais

| Operador | Significado | Exemplo |
|---|---|---|
| `==` | igual a | `a == b` |
| `!=` | diferente de | `a != b` |
| `>` | maior que | `a > b` |
| `<` | menor que | `a < b` |
| `>=` | maior ou igual | `a >= b` |
| `<=` | menor ou igual | `a <= b` |

## Lógicos

| Operador | Significado | Exemplo |
|---|---|---|
| `&&` | E | `idade >= 18 && idade <= 65` |
| `||` | OU | `nota >= 7 || recuperacao == true` |
| `!` | NÃO | `!(idade >= 18)` |

As expressões condicionais produzem valores booleanos: `true` ou `false`.
