# Guia de fluxogramas de decisão

A aula apresenta o fluxograma como uma representação visual do algoritmo.

## Símbolos básicos

- **Terminal:** início/fim.
- **Processo:** ação ou processamento.
- **Decisão:** pergunta/condição, com caminhos como Sim/Não.
- **Seta:** direção do fluxo.

## Para converter fluxograma em Java

1. Identifique as decisões.
2. Transforme cada decisão em `if`, `else if`, `else` ou `switch`.
3. Siga a sequência indicada pelas setas.
4. Transforme processos em comandos/blocos Java.
5. Verifique todos os caminhos.
6. Teste diferentes entradas.
