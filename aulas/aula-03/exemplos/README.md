# Exemplos

Os exemplos seguem a progressão da aula:

1. `if` simples;
2. `if-else`;
3. `else if`;
4. `switch-case`;
5. escolha entre `if` e `switch`;
6. operador ternário;
7. situações-problema contemporâneas.

Todos os exemplos são programas Java independentes e podem ser compilados individualmente.
