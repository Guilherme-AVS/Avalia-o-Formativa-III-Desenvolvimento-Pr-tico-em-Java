# Exercício 9 — Difícil

## Enunciado

Crie um ArrayList e permita adicionar números até o usuário escolher parar.

## Objetivos
- praticar os conceitos apresentados na Aula 07;
- escolher a estrutura de dados adequada;
- produzir código legível e executável.

## Entrega sugerida

Crie uma classe Java com o mesmo nome do arquivo e teste com pelo menos dois conjuntos de dados.

## Critérios de conferência
- [ ] Compila.
- [ ] Usa a estrutura solicitada.
- [ ] Percorre os elementos corretamente.
- [ ] Evita índices inválidos.
- [ ] Saída está coerente.
