# Aula 07 — Arrays e ArrayList em Java

**Disciplina:** Programação Orientada a Objetos  
**Semestre:** 2026.2  
**Aula:** 07/20  
**Tema:** Arrays e ArrayList em Java — armazenando e processando coleções de dados com eficiência

## Objetivos

Ao final da aula, o estudante deverá ser capaz de:

- criar, inicializar e percorrer arrays com `for` e `for-each`;
- trabalhar com arrays de tipos primitivos, objetos e multidimensionais;
- utilizar arrays como parâmetros e retorno de métodos;
- criar e manipular `ArrayList`;
- adicionar, remover, consultar, alterar e percorrer elementos;
- reconhecer a diferença entre `.length` e `.size()`;
- escolher entre `array` e `ArrayList` conforme o problema.
