# Diagramas da Aula 07

Os diagramas são conceituais e editáveis em Draw.io. Eles apoiam:

1. índices;
2. comparação entre `for` e `for-each`;
3. arrays em métodos;
4. matrizes;
5. array × ArrayList;
6. progressão conceitual até objetos.

Eles não substituem os exemplos Java; funcionam como mapas visuais do conteúdo.
