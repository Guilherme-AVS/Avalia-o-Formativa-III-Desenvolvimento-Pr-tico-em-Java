# Critérios de integridade do pacote

Este pacote deve ser distribuído sem o PDF de referência.

Validações realizadas na geração:

- arquivos `.java` compiláveis;
- arquivos `.drawio` com XML bem-formado;
- nenhuma pasta vazia;
- nenhum `.pdf`;
- nenhum `.svg`;
- nenhum `.png`.

A nomenclatura dos arquivos Java segue a convenção de o nome do arquivo corresponder à classe pública.
