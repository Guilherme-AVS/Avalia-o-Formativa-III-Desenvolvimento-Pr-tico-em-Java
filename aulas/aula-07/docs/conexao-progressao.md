# Conexão curricular

Aula 07 consolida estruturas de dados simples antes da modelagem de objetos.

```text
Aula 04 — loops
       ↓
Aula 05 — métodos
       ↓
Aula 06 — Strings
       ↓
Aula 07 — arrays / ArrayList
       ↓
Aula 08 — classes e objetos
```

A apresentação também aponta uma conexão futura com a Aula 17, quando Collections e Generics serão aprofundados.
