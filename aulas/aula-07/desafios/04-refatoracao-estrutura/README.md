# Desafio 04 — Escolha da Estrutura

Receba um problema em que a quantidade de elementos pode variar.

1. Resolva inicialmente com array.
2. Identifique a limitação do tamanho fixo.
3. Reescreva com ArrayList.
4. Registre as diferenças de código e de operações.

O foco é justificar tecnicamente a escolha da estrutura.
