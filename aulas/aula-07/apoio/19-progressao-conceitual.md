# Progressão conceitual

A aula apresenta uma progressão:

**Variável → Array → ArrayList → Objetos**

A ideia é sair de valores isolados, passar para coleções de tamanho fixo, depois coleções dinâmicas e, na Aula 08, usar essas estruturas para representar entidades do mundo real.

Exemplo de ponte:

```text
String[] nomes
      ↓
Aluno[] alunos
      ↓
ArrayList<Aluno> alunos
```
