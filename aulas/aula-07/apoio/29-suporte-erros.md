# Apoio — Diagnóstico rápido

### `ArrayIndexOutOfBoundsException`
Verifique se o índice está entre `0` e `length - 1`.

### `IndexOutOfBoundsException` no ArrayList
Verifique se o índice está entre `0` e `size() - 1`.

### `cannot find symbol: ArrayList`
Adicione:

```java
import java.util.ArrayList;
```

### `ArrayList<int>`
Use:

```java
ArrayList<Integer>
```

### `length` em ArrayList
Use:

```java
size()
```
