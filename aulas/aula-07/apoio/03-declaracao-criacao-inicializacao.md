# Declaração, criação e inicialização

```java
int[] numeros;
numeros = new int[5];
```

Forma usual:

```java
int[] numeros = new int[5];
```

Inicialização com valores:

```java
int[] numeros = {10, 20, 30};
String[] nomes = {"Ana", "Bruno", "Carlos"};
```

Também é possível:

```java
int[] numeros = new int[]{10, 20, 30};
```
