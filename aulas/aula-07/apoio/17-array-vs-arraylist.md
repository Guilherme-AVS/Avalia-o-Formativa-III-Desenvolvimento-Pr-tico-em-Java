# Array × ArrayList

| Característica | Array | ArrayList |
|---|---|---|
| Tamanho | fixo | dinâmico |
| Índice | `arr[i]` | `list.get(i)` |
| Tamanho | `.length` | `.size()` |
| `add/remove` | não | sim |
| Primitivos | sim | wrappers |
| Objetos | sim | sim |

Regra prática trabalhada na aula: tamanho conhecido e fixo favorece array; necessidade de adicionar/remover elementos favorece `ArrayList`.
