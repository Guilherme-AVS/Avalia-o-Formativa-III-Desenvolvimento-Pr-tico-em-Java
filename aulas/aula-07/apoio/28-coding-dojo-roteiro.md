# Roteiro do Coding Dojo

## Formação
Equipes de 4–5 pessoas.

## Rodadas
- Rodada 1: grupo inicia a solução.
- Rodada 2: próximo grupo continua.
- Rodada 3: outro grupo finaliza ou refatora.
- Discussão final: todos analisam a solução.

## Problema
Implementar o Boletim da Turma, começando com array e migrando para ArrayList.

## Perguntas para discussão
- Onde o índice é necessário?
- Onde `for-each` simplifica?
- Onde `length` aparece?
- Onde `size()` aparece?
- Qual solução é mais adequada se novos estudantes forem adicionados?
