# UML — Aula 06

A Aula 06 ainda não introduz diagramas de classes como foco principal. Os diagramas aqui representam o comportamento de processamento textual e a cadeia de operações sobre objetos `String`.

Arquivos:
1. criação e referência;
2. acesso por índice;
3. comparação;
4. transformação;
5. pesquisa e extração;
6. encadeamento.
