# 07 — Comparação lexicográfica

`compareTo()` compara Strings segundo a ordem lexicográfica.

Resultado:
- menor que zero → primeira String vem antes;
- zero → conteúdo equivalente;
- maior que zero → primeira String vem depois.

`compareToIgnoreCase()` ignora diferenças de maiúsculas e minúsculas.

Nesta aula, o objetivo é compreender a comparação, não implementar algoritmos de ordenação.
