# 03 — Concatenação

O operador `+` concatena textos.

`String mensagem = "Olá, " + nome + "!";`

Também é possível usar `+=`.

Ao concatenar um texto com outro tipo, o Java converte o valor para uma representação textual.

Para os exemplos desta aula, `+` é suficiente. Em processamento intensivo dentro de loops, `StringBuilder` pode ser mais adequado.
