# 04 — length() e charAt()

`length()` retorna o número de caracteres.

`charAt(i)` retorna o caractere existente no índice `i`.

Índices começam em `0`.

Para `"Maria"`:
- índice 0 → `M`
- índice 1 → `a`
- índice 2 → `r`
- índice 3 → `i`
- índice 4 → `a`

Atenção à diferença que será importante na Aula 07:

- String → `texto.length()`
- array → `numeros.length`
