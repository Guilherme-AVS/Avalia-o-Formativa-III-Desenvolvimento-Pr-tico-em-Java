# 01 — String é objeto

Em Java, `String` é uma classe da API Java (`java.lang.String`), e não um tipo primitivo.

Exemplos:

`String nome = "Maria";`
`String curso = "Ciência da Computação";`

A diferença é importante porque objetos oferecem métodos.

Exemplos:

- `nome.length()`
- `nome.toUpperCase()`
- `nome.contains("Maria")`

A Aula 06 é uma ponte importante para POO: o estudante já começa a chamar comportamentos sobre objetos.
