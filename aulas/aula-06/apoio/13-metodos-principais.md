# 13 — Tabela de métodos

| Método | Função |
|---|---|
| `length()` | tamanho |
| `charAt(i)` | caractere no índice |
| `equals()` | compara conteúdo |
| `equalsIgnoreCase()` | compara ignorando caixa |
| `compareTo()` | comparação lexicográfica |
| `toUpperCase()` | maiúsculas |
| `toLowerCase()` | minúsculas |
| `trim()` | remove espaços nas extremidades |
| `contains()` | pesquisa trecho |
| `startsWith()` | verifica prefixo |
| `endsWith()` | verifica sufixo |
| `substring()` | extrai parte |
| `replace()` | substitui texto |
| `replaceAll()` | substitui usando regex |
| `indexOf()` | primeira ocorrência |
| `lastIndexOf()` | última ocorrência |
