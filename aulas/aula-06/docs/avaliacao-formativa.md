# Avaliação Formativa — Aula 06

| Critério | Evidência |
|---|---|
| String como objeto | Explica a diferença para primitivos |
| Índices | Usa corretamente 0 até `length()-1` |
| length | Obtém tamanho corretamente |
| charAt | Obtém caractere correto |
| equals | Compara conteúdo |
| Pesquisa | Usa contains/indexOf adequadamente |
| Transformação | Usa métodos sem confundir imutabilidade |
| substring | Respeita índice final exclusivo |
| Loop | Percorre a String corretamente |
| Modularização | Cria métodos quando a solução exige reaproveitamento |

## Exit ticket
Explique em uma frase por que `nome.toUpperCase();` não altera necessariamente o valor armazenado em `nome`.
