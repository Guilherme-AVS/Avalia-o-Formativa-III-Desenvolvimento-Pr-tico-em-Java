# Exercício 06

## Nível
⭐⭐

## Enunciado
Leia duas Strings e compare seus conteúdos usando equals() e equalsIgnoreCase().

## Requisitos
- Use os métodos da classe `String` adequados.
- Não compare conteúdo com `==`.
- Respeite os índices.
- Teste pelo menos dois casos.

## Reflexão
Qual método de `String` foi essencial para resolver o problema?
