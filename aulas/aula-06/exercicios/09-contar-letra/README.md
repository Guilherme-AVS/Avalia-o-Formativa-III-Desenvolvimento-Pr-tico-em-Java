## Nível

## Enunciado
Leia uma frase e uma letra e conte quantas vezes a letra aparece.

## Requisitos
- Use os métodos da classe `String` adequados.
- Não compare conteúdo com `==`.
- Respeite os índices.
- Teste pelo menos dois casos.

## Reflexão
