## Enunciado
Leia dois nomes e informe a relação lexicográfica entre eles usando compareTo().

## Requisitos
- Use os métodos da classe `String` adequados.
- Não compare conteúdo com `==`.
- Respeite os índices.
- Teste pelo menos dois casos.
