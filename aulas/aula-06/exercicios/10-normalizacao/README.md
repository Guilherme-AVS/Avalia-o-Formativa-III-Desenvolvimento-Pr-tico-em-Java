## Enunciado
Normalize um nome removendo espaços nas extremidades e convertendo para maiúsculas.

## Requisitos
- Use os métodos da classe `String` adequados.
- Não compare conteúdo com `==`.
- Respeite os índices.
- Teste pelo menos dois casos.
