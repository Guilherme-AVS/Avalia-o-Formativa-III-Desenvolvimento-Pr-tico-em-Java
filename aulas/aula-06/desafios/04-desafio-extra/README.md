# Desafio 04 — Análise Textual Completa

Implemente uma versão completa do desafio da aula.

O programa deve ser modularizado em métodos e tratar também:
- frase vazia;
- frase com apenas uma palavra;
- letra em maiúscula ou minúscula;
- palavra pesquisada ausente.

Priorize legibilidade e reaproveitamento.
