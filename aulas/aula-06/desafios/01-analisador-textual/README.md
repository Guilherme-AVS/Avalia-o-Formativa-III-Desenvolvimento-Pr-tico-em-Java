# Desafio 01 — Analisador Textual Completo

Receba uma frase e uma letra.

Gere:
1. quantidade total de caracteres;
2. quantidade de espaços;
3. primeira palavra;
4. última palavra;
5. quantidade de ocorrências da letra;
6. frase em maiúsculas;
7. frase em minúsculas.

### Restrição
Use `indexOf()`, `lastIndexOf()` e `substring()` para extrair a primeira e a última palavra.
