# Aula 06 — Strings em Java

Material completo da Aula 06 da disciplina **Programação Orientada a Objetos — 2026.2**.

## Tema
**Strings em Java: criação, comparação, manipulação e processamento de textos.**

## Objetivos
Ao final da aula, o estudante deverá:
- explicar o que é `String` e diferenciá-la de tipos primitivos;
- comparar conteúdo com `equals()` e `equalsIgnoreCase()`;
- compreender por que `==` não deve ser usado para comparar conteúdo;
- usar `length()` e `charAt()`;
- percorrer uma String com `for`;
- transformar textos com `toUpperCase()`, `toLowerCase()` e `trim()`;
- pesquisar com `contains()`, `startsWith()`, `endsWith()`, `indexOf()` e `lastIndexOf()`;
- extrair partes com `substring()`;
- substituir conteúdo com `replace()` e `replaceAll()`;
- compreender a imutabilidade de `String`;
- encadear métodos;
- aplicar métodos de String em problemas reais de validação e análise textual.
