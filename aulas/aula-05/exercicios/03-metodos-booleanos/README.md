# Exercício 03

## Enunciado
Crie `ePar(int n)`, `ePositivo(int n)` e `eMaiorDeIdade(int idade)`, retornando `boolean`.

## Regras
- Use métodos `static`.
- Escolha nomes descritivos.
- Evite repetir código.
- O `main` deve coordenar as chamadas quando houver mais de uma responsabilidade.

## Entrega
Envie o arquivo `.java` solicitado pelo professor.
