# 05 — Parâmetros e argumentos

**Parâmetro** é a variável declarada na definição do método.

**Argumento** é o valor ou expressão fornecido na chamada.

Exemplo:

`public static int somar(int a, int b)`

Aqui `a` e `b` são parâmetros.

`somar(3, 7)`

Aqui `3` e `7` são argumentos.

## Ordem
A associação acontece pela posição:
- primeiro argumento → primeiro parâmetro;
- segundo argumento → segundo parâmetro.

Os nomes das variáveis usadas na chamada não precisam coincidir com os nomes dos parâmetros.
