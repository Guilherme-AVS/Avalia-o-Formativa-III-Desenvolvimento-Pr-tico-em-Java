# 04 — Métodos com retorno

O tipo declarado antes do nome informa qual valor será devolvido.

Exemplo:

`public static double calcularMedia(double n1, double n2)`

O `return`:
1. encerra a execução do método;
2. envia o valor para o ponto de chamada.

O resultado pode ser:
- armazenado em uma variável;
- usado diretamente em uma expressão;
- passado para outro método.

Exemplo conceitual:

`double media = calcularMedia(8.0, 9.0);`
