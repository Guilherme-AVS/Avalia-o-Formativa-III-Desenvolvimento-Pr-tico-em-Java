# 12 — API Java: `Math`

A API Java fornece métodos prontos.

Exemplos:
- `Math.sqrt(25)` → raiz quadrada;
- `Math.pow(2, 3)` → potência;
- `Math.max(10, 20)` → maior valor;
- `Math.min(10, 20)` → menor valor;
- `Math.abs(-5)` → valor absoluto.

A ideia é reutilizar soluções disponíveis na API em vez de reinventar operações já fornecidas pela linguagem.
