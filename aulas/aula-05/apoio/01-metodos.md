# 01 — O que são métodos?

Um método é uma unidade de comportamento: um bloco de código com nome próprio que realiza uma tarefa específica e pode ser chamado quantas vezes for necessário.

## Por que usar métodos?
- reutilização de código;
- modularização;
- legibilidade;
- manutenção;
- testabilidade.

### Exemplo

`public static void saudacao()`

O método é definido uma vez e pode ser chamado várias vezes.

## Ideia central
**Escreva uma vez, chame quando precisar.**

Um método é especialmente útil quando:
- o mesmo trecho de código aparece em mais de um lugar;
- existe uma tarefa bem definida;
- o `main` ficou longo;
- a operação precisa ser testada isoladamente.
