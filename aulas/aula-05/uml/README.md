# UML — Aula 05

A Aula 05 ainda não introduz modelagem de classes como conteúdo principal. Por isso, os diagramas desta pasta não simulam classes de forma artificial.

Eles visualizam:
1. anatomia de um método;
2. fluxo de chamada e retorno;
3. decomposição de um programa monolítico;
4. relação entre `main` e métodos;
5. decisão de `void` versus retorno;
6. sobrecarga.

Os arquivos `.drawio` são editáveis no diagrams.net.
