# Aula 05 — Métodos em Java

Material completo da Aula 05 da disciplina **Programação Orientada a Objetos — 2026.2**.

## Tema
**Métodos em Java: modularização, parâmetros, retorno e sobrecarga.**

## Objetivos
Ao final da aula, o estudante deve conseguir:
- explicar o que é um método e por que ele é utilizado;
- diferenciar métodos `void` de métodos que retornam valores;
- criar métodos com e sem parâmetros;
- utilizar valores de retorno;
- distinguir parâmetro de argumento;
- compreender escopo de variáveis locais e parâmetros;
- compreender passagem de tipos primitivos por valor;
- criar métodos `static`;
- criar métodos sobrecarregados;
- reconhecer a assinatura de um método;
- compreender promoção de tipos em chamadas sobrecarregadas;
- utilizar métodos da API Java, especialmente `Math`;
- refatorar um `main` monolítico em métodos com responsabilidades claras.
