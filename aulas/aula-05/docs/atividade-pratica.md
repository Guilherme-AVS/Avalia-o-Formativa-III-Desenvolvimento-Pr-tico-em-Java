# Atividade Prática — Refatoração

## Antes
Um único `main` lê duas notas, calcula a média e exibe aprovação.

## Depois
Separe em:
- `lerNota`;
- `calcularMedia`;
- `exibirResultado`.

## Critério de sucesso
O `main` deve permitir que outro estudante entenda o fluxo sem precisar ler os detalhes internos de cada operação.
