# Avaliação Formativa — Aula 05

Use esta lista para observação rápida durante a prática.

| Critério | Evidência |
|---|---|
| Método sem parâmetro | Cria e chama corretamente |
| `void` | Identifica ausência de retorno |
| Retorno | Usa `return` corretamente |
| Parâmetros | Declara tipos e nomes |
| Argumentos | Faz chamadas compatíveis |
| Escopo | Não tenta acessar variável local de outro método |
| Sobrecarga | Diferencia por parâmetros |
| Modularização | Separa responsabilidades |
| DRY | Evita duplicação |
| API | Reutiliza `Math` |
