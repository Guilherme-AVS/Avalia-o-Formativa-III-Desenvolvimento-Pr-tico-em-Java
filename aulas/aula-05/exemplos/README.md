# Exemplos da Aula 05

Os exemplos seguem uma progressão:

1. método sem parâmetros;
2. `void` com parâmetro;
3. `return;` antecipado;
4. retorno;
5. múltiplos parâmetros;
6. parâmetros de tipos diferentes;
7. parâmetro × argumento;
8. passagem por valor;
9. escopo;
10. `static`;
11. sobrecarga;
12. sobrecarga pela ordem;
13. promoção;
14. API `Math`;
15. integração com loops;
16. calculadora;
17. modularização;
18. desafio progressivo;
19. métodos booleanos;
20. refatoração;
21. integração.

Todos os exemplos são independentes e não dependem de pacotes externos.
