# Aula 12 — Polimorfismo em Java

Material completo da Aula 12/23 de Programação Orientada a Objetos — 2026.2.

## Objetivos
- Compreender polimorfismo e sua relação com herança.
- Distinguir overload de override e ligação estática de dinâmica.
- Aplicar `@Override`, `final`, upcasting e downcasting.
- Usar `instanceof` com segurança, inclusive Pattern Matching (Java 16+).
- Construir arrays, listas e parâmetros polimórficos.
- Refatorar condicionais baseadas em tipo.
- Aplicar o LSP e reconhecer sinais de hierarquias inadequadas.
