# Boas Praticas

- Sempre use `@Override` ao sobrescrever.
- Programe para a abstração.
- Prefira polimorfismo a `instanceof` quando o comportamento pertence ao objeto.
- Use Pattern Matching para `instanceof` quando fizer sentido.
- Faça downcasting apenas quando realmente necessário.
- Evite `final` sem uma razão de design.
- Respeite LSP.
- Não transforme toda condicional em polimorfismo: use a solução mais simples que represente corretamente a variação.
