# 01 Logistica Sem If

## Desafio integrador
Implemente um sistema de logística com `EntregaTerrestre`, `EntregaAerea` e `EntregaExpressa`. O cliente deve operar sobre `Entrega` e não pode testar o tipo concreto.

**Obrigatório:** `@Override`, coleção polimórfica, método `calcularFrete()`, relatório final e pelo menos uma nova modalidade criada pelo estudante.

**Rubrica:** 2,0 arquitetura; 2,0 polimorfismo; 1,0 qualidade.
