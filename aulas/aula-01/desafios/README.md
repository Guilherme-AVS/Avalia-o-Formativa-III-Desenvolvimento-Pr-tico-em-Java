# Desafios — Aula 01

Os desafios são opcionais e servem para ampliar a prática sem antecipar conteúdos das próximas aulas.

## Desafio disponível

**Cartão de apresentação no console**

O estudante deve criar uma saída organizada que apresente sua identidade acadêmica e uma pequena mensagem sobre por que deseja aprender Java.
