# Desafio 01 — Cartão de apresentação

Crie `CartaoDeApresentacao.java`.

O programa deve imprimir um cartão textual contendo:

- nome;
- curso;
- disciplina;
- semestre;
- uma área da Computação de interesse;
- uma frase curta sobre o que espera aprender em POO.

## Restrições

Use somente:

- uma classe;
- `main`;
- `System.out.println`;
- textos literais.

Não use ainda variáveis, `if`, laços, métodos próprios ou coleções.
