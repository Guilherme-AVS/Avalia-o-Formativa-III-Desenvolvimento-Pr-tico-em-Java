# Exemplos da Aula 01

Os exemplos acompanham os conceitos apresentados na aula.

| Arquivo | Conceito principal |
|---|---|
| `HelloJava.java` | primeiro programa e `main` |
| `DiagnosticoAmbiente.java` | verificação do ambiente Java |
| `HardwareSoftware.java` | hardware, software e linguagem |
| `LinguagensProgramacao.java` | níveis de linguagem e Java |
| `FluxoCompilacao.java` | `.java`, `javac`, `.class` e JVM |
| `ComentariosJava.java` | comentários `//`, `/* */` e `/** */` |
| `MeusDados.java` | tarefa inicial: imprimir dados |

## Como executar

```text
javac *.java
java HelloJava
```

Os exemplos foram propositalmente mantidos simples para que o estudante possa observar a estrutura da linguagem antes de introduzir variáveis, condicionais, laços e outros recursos que serão estudados nas aulas seguintes.
