# Checklist de aprendizagem — Aula 01

Marque cada item após conseguir explicá-lo ou executá-lo.

- [ ] Sei diferenciar hardware e software.
- [ ] Sei explicar o papel de uma linguagem de programação.
- [ ] Sei explicar o que é Java.
- [ ] Reconheço a ideia de portabilidade do Java.
- [ ] Sei explicar o que é bytecode.
- [ ] Sei descrever `.java → javac → .class → JVM`.
- [ ] Sei diferenciar JDK, JRE e JVM.
- [ ] Consigo executar `java -version`.
- [ ] Consigo executar `javac -version`.
- [ ] Sei por que `Hello.java` deve corresponder a `public class Hello`.
- [ ] Sei identificar o `main`.
- [ ] Sei usar `System.out.println`.
- [ ] Sei escrever comentários de uma linha e múltiplas linhas.
- [ ] Consigo executar um programa Java simples.
- [ ] Consigo explicar, em nível introdutório, o que é POO.
- [ ] Estou preparado para a Aula 02: tipos, variáveis e operadores.
