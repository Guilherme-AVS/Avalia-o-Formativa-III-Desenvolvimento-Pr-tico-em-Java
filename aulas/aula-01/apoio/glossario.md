# Glossário — Aula 01

| Termo | Significado |
|---|---|
| Hardware | Parte física do computador. |
| Software | Programas e sistemas executados pelo computador. |
| Linguagem de máquina | Instruções representadas no nível diretamente executável pelo processador. |
| Assembly | Linguagem de baixo nível baseada em mnemônicos. |
| Linguagem de alto nível | Linguagem mais próxima da forma de raciocínio humano. |
| Java | Linguagem de programação orientada a objetos e plataforma computacional. |
| Bytecode | Código intermediário produzido pelo compilador Java. |
| JDK | Java Development Kit. Ambiente de desenvolvimento. |
| JRE | Java Runtime Environment. Ambiente de execução. |
| JVM | Java Virtual Machine. Executa bytecode Java. |
| `javac` | Compilador Java. |
| `main` | Método de entrada de uma aplicação Java simples. |
| POO | Programação Orientada a Objetos. |
| Classe | Unidade básica de organização da programação orientada a objetos em Java. |
| Garbage Collector | Mecanismo de gerenciamento automático de memória da JVM. |
