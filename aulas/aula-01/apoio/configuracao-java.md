# Configuração do ambiente Java

## 1. JDK

A aula indica **JDK 17 ou superior**, destacando o JDK 17 como versão LTS recomendada.

O JDK é o ambiente de desenvolvimento e inclui ferramentas como:

- `javac`;
- `java`;
- `javadoc`;
- `jar`;
- `jdb`.

## 2. IDE

A aula apresenta:

- IntelliJ IDEA;
- Eclipse;
- VS Code.

A apresentação recomenda VS Code.

## 3. Verificação

No terminal:

```text
java -version
javac -version
```

Os dois comandos devem responder com uma versão instalada.

## 4. PATH e JAVA_HOME

Durante a instalação, pode ser necessário configurar as variáveis de ambiente `PATH` e `JAVA_HOME`, conforme o sistema operacional.

## 5. Primeiro teste

Crie `HelloJava.java`, compile com `javac` e execute com `java`.
