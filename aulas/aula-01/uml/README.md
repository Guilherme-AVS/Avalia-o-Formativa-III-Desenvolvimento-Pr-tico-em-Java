# Diagramas UML e conceituais — Aula 01

A Aula 01 ainda não trabalha modelagem detalhada de classes. Por isso, os diagramas desta pasta são **conceituais e de apoio**, preparando o estudante para a modelagem UML das aulas seguintes.

## Diagramas

1. `fluxo-compilacao.drawio` — fonte → compilador → bytecode → JVM → execução.
2. `ambiente-java-jdk-jre-jvm.drawio` — relação conceitual entre JDK, JRE e JVM.
3. `primeira-visao-poo.drawio` — primeira visão de POO: classe, objeto, atributos e comportamentos.
4. `estrutura-programa-java.drawio` — elementos de um programa Java simples.

Todos os arquivos são editáveis no diagrams.net (draw.io).
