# Exercício 02 — Java e portabilidade

Explique com suas palavras:

1. O que é Java?
2. O que significa a ideia "Write Once, Run Anywhere"?
3. Qual é o papel do bytecode?
4. Qual é o papel da JVM?

Finalize com um pequeno exemplo hipotético mostrando como o mesmo arquivo `.class` pode ser executado em sistemas operacionais diferentes.
