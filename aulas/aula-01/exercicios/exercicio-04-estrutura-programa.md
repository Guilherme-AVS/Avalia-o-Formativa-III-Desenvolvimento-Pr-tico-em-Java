# Exercício 04 — Estrutura de um programa Java

Analise a estrutura:

```text
public class Hello {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}
```

Responda:

1. Qual é o nome da classe?
2. Qual deve ser o nome do arquivo?
3. Qual é o ponto de entrada do programa?
4. O que significa `public` no método `main`?
5. O que significa `static`?
6. O que significa `void`?
7. Qual instrução produz a saída no console?
