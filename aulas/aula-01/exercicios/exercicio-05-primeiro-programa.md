# Exercício 05 — Meu primeiro programa

Crie um programa chamado `MeusDados.java` que imprima no console:

- seu nome;
- seu curso;
- a disciplina;
- o semestre;
- uma tecnologia que você gostaria de aprender.

### Requisitos

- o arquivo deve se chamar `MeusDados.java`;
- a classe pública deve se chamar `MeusDados`;
- deve existir um método `main`;
- use `System.out.println`;
- não é necessário usar variáveis nesta aula.

### Teste

Compile:

```text
javac MeusDados.java
```

Execute:

```text
java MeusDados
```
