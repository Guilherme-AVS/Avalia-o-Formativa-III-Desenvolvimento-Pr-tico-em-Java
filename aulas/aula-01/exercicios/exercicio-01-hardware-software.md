# Exercício 01 — Hardware e Software

Classifique cada item como **hardware** ou **software** e justifique brevemente:

1. CPU
2. sistema operacional
3. memória RAM
4. editor de código
5. monitor
6. linguagem de programação

Depois explique, em duas ou três frases, por que uma linguagem de programação pode ser considerada uma ponte entre o programador e o computador.

**Objetivo:** compreender o contexto em que um programa Java é executado.
