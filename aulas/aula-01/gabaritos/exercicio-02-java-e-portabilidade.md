# Gabarito — Exercício 02

1. Java é uma linguagem de programação orientada a objetos e também uma plataforma computacional.
2. "Write Once, Run Anywhere" expressa a ideia de portabilidade: o código compilado para bytecode pode ser executado por uma JVM adequada à plataforma.
3. Bytecode é o código intermediário produzido pelo compilador Java.
4. A JVM carrega e executa o bytecode na plataforma específica.

Exemplo: um mesmo `Programa.class` pode ser levado para um computador com JVM para Windows e para outro com JVM para Linux. Cada JVM executa o bytecode em seu respectivo sistema.
