# Exercício 02 — Contagem regressiva

## Enunciado

Exiba os números de 10 a 1 usando `while`.

## Requisitos
- use a estrutura de repetição adequada;
- teste valores de fronteira;
- mantenha a variável de controle corretamente atualizada;
- apresente uma solução legível.

## Entrega
Um arquivo `.java` e uma pequena descrição da estratégia utilizada.
