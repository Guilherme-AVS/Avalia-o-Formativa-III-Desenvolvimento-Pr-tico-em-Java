# `while`

Sintaxe:

```java
while (condicao) {
    // corpo
}
```

A condição é testada **antes** de cada iteração. Portanto, o corpo pode executar zero vezes.

Casos de uso:
- número desconhecido de repetições;
- aguardar uma condição externa;
- menus interativos;
- validação de entrada.

A variável de controle precisa ser atualizada quando ela participa da condição de parada.
