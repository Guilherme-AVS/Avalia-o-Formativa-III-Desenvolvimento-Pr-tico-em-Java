# `do-while`

Sintaxe:

```java
do {
    // corpo
} while (condicao);
```

A condição é testada **depois** do corpo. Por isso, o bloco executa pelo menos uma vez.

É apropriado para:
- menus;
- validações;
- solicitações de senha;
- qualquer situação em que a primeira execução seja obrigatória.

Atenção ao `;` depois de `while (condicao)`.
