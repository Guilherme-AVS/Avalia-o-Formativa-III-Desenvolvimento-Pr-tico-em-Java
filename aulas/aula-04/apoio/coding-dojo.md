# Coding Dojo

A aula propõe um Coding Dojo colaborativo.

## Objetivos
- aprender pela prática coletiva;
- desenvolver resolução de problemas;
- praticar programação em pares;
- aprimorar comunicação técnica;
- explorar diferentes soluções.

## Grupos
Equipes de 4–5 pessoas.

## Papéis
- **Piloto:** escreve o código.
- **Copiloto:** orienta e sugere.
- **Plateia:** observa e registra pontos para discussão.

Os papéis devem ser rotativos. O foco é aprendizagem, não competição.
