# `for-each` (enhanced for)

O `for-each` percorre arrays e coleções sem exigir o controle manual do índice.

```java
String[] frutas = {"Maçã", "Banana", "Laranja"};

for (String fruta : frutas) {
    System.out.println(fruta);
}
```

É especialmente útil quando a intenção é processar todos os elementos de uma estrutura.
