# `for`

Sintaxe:

```java
for (inicialização; condição; atualização) {
    // corpo
}
```

Use `for` quando o número de iterações é conhecido ou quando existe uma variável de controle bem definida.

Exemplos de padrões:

```java
for (int i = 1; i <= 5; i++) { }
for (int i = 10; i > 0; i--) { }
for (int i = 0; i < 50; i += 5) { }
for (int i = 0, j = 10; i < j; i++, j--) { }
```
