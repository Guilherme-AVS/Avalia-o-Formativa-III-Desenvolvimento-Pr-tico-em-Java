# Desafio 01 — Plataforma de pagamentos

Integre classe abstrata, herança, encapsulamento e polimorfismo. Crie uma hierarquia `MeioPagamento` com PIX, cartão e boleto.

## Requisitos mínimos
1. Pelo menos três classes relacionadas.
2. Pelo menos um construtor parametrizado.
3. Estado encapsulado com `private`.
4. Pelo menos um método sobrescrito com `@Override`.
5. Pelo menos uma chamada polimórfica.
6. Demonstração no `Main`.

## Evidências
- explique a hierarquia;
- indique onde ocorre polimorfismo;
- indique uma regra de encapsulamento;
- rastreie uma execução.

## Rubrica
- 30% conceito
- 30% funcionamento
- 20% rastreamento/explicação
- 20% organização
