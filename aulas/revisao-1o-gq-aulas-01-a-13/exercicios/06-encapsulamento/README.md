# Exercício 06 — Encapsulamento

Crie `ContaDigital` com saldo privado e operações `depositar` e `sacar`, rejeitando valores inválidos.

## Entrega
- Código Java compilável.
- Um `Main.java` para demonstrar o comportamento.
- Comentário curto explicando a decisão principal.

## Critérios
- 40% correção lógica
- 25% domínio do conceito
- 20% organização do código
- 15% clareza da explicação
