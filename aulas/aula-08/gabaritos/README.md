# Gabaritos

Os gabaritos são **uma possível solução**. Em modelagem orientada a objetos, outras soluções podem ser válidas quando são coerentes com o problema e tecnicamente justificadas.

Critérios principais:

- responsabilidade bem definida;
- atributos coerentes;
- métodos relacionados ao domínio;
- encapsulamento adequado;
- relacionamentos e multiplicidades justificáveis;
- UML consistente com Java.
