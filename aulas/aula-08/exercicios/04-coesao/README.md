# Exercício 4 — Médio

## Enunciado

Analise uma classe `SistemaEscolar` que possui métodos de cadastrar aluno, enviar e-mail, gerar relatório e calcular nota. Separe responsabilidades em classes coerentes.

## Entrega
- código Java;
- explicação das decisões de modelagem;
- quando solicitado, diagrama UML em Draw.io.

## Checklist
- [ ] Classes com nomes em PascalCase.
- [ ] Atributos coerentes e, quando aplicável, `private`.
- [ ] Métodos relacionados às responsabilidades.
- [ ] Relacionamentos justificados.
- [ ] Código compila.
