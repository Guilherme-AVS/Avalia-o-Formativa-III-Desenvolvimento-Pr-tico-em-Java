# Exercício 3 — Fácil

## Enunciado

Modele `Aluno` com nome, matrícula e duas notas. Crie um método que calcule a média.

## Entrega
- código Java;
- explicação das decisões de modelagem;
- quando solicitado, diagrama UML em Draw.io.

## Checklist
- [ ] Classes com nomes em PascalCase.
- [ ] Atributos coerentes e, quando aplicável, `private`.
- [ ] Métodos relacionados às responsabilidades.
- [ ] Relacionamentos justificados.
- [ ] Código compila.
