# Exercício 7 — Difícil

## Enunciado

Modele `Biblioteca` e `Livro` usando agregação. Mostre que um livro pode existir antes de ser adicionado à biblioteca.

## Entrega
- código Java;
- explicação das decisões de modelagem;
- quando solicitado, diagrama UML em Draw.io.
