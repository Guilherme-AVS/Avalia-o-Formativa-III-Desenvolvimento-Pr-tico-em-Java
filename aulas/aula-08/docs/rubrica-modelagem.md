# Rubrica — Modelagem de Classes

| Critério | Evidência |
|---|---|
| Identificação | Classes representam entidades relevantes |
| Atributos | Características possuem tipos adequados |
| Métodos | Comportamentos pertencem às classes corretas |
| Encapsulamento | Atributos privados quando apropriado |
| Coesão | Responsabilidades relacionadas |
| Acoplamento | Dependências necessárias e explícitas |
| Relacionamentos | Tipo e direção coerentes |
| Multiplicidade | 1:1 e 1:N representados corretamente |
| UML | Notação consistente |
| Java | Código coerente com o modelo |

A rubrica avalia a coerência entre problema, UML e implementação.
