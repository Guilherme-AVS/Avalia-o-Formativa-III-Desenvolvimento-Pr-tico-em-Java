# PBL — Sistema de Biblioteca

## Problema

Uma biblioteca precisa controlar acervo, usuários e empréstimos.

## Etapa 1 — Análise
Identificar entidades e requisitos.

## Etapa 2 — Modelagem
Definir atributos, métodos e visibilidade.

## Etapa 3 — Relacionamentos
Definir 1:1, 1:N, agregação, composição ou dependência quando justificável.

## Etapa 4 — UML
Criar o diagrama no Draw.io.

## Etapa 5 — Código
Implementar pelo menos uma classe completamente.

## Etapa 6 — Apresentação
Cada grupo explica as decisões de modelagem.

> Quem é responsável por quê?
