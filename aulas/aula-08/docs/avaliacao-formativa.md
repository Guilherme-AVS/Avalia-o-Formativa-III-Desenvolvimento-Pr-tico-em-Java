# Avaliação formativa — Aula 08

## Evidências

O estudante consegue:

- identificar classes candidatas;
- separar atributos e comportamentos;
- escrever uma classe Java coerente;
- aplicar `private`;
- criar getters/setters básicos;
- explicar alta coesão;
- explicar baixo acoplamento;
- identificar associações;
- distinguir 1:1 e 1:N;
- diferenciar agregação, composição e dependência;
- representar a modelagem em UML.

## Miniatividade

Dado:

> Uma clínica possui médicos e pacientes. Cada consulta relaciona um médico a um paciente.

Solicite:

1. classes;
2. atributos;
3. métodos;
4. relação;
5. multiplicidade;
6. UML.

## Feedback

Não avaliar apenas sintaxe. Verificar se o código representa adequadamente o domínio.
