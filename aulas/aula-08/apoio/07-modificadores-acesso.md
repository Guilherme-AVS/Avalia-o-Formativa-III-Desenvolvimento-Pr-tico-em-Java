# Modificadores de acesso

| Modificador | Ideia central |
|---|---|
| `private` | somente a própria classe |
| `public` | acesso geral |
| `protected` | classe, pacote e subclasses |
| default | acesso no mesmo pacote |

Na modelagem inicial, a recomendação é manter atributos `private` e expor somente os comportamentos e acessos necessários.
