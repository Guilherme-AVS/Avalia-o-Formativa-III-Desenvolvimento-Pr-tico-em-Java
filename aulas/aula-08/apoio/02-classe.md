# Classe

Uma classe é um modelo que define:

- estrutura: atributos;
- comportamento: métodos;
- estado: valores dos atributos.

Exemplo conceitual:

```text
Classe: Livro

atributos:
- titulo
- autor
- isbn

métodos:
- emprestar()
- devolver()
- estaDisponivel()
```

A classe não representa um livro específico; ela define como objetos `Livro` serão estruturados.
