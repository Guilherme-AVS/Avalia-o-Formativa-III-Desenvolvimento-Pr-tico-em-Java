# Alta coesão

Coesão mede o quanto os elementos de uma classe estão relacionados a um propósito comum.

## Alta coesão

`Livro` concentra dados e comportamentos relacionados ao conceito de livro.

## Baixa coesão

Uma classe `Livro` que também envia e-mails, processa pagamentos e gera relatórios de toda a biblioteca acumula responsabilidades diferentes.
