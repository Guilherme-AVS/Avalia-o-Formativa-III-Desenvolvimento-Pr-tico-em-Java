# Nomenclatura

Convenções usadas nesta aula:

| Elemento | Convenção | Exemplo |
|---|---|---|
| Classe | PascalCase | `Biblioteca` |
| Método | camelCase | `adicionarLivro()` |
| Atributo | camelCase | `dataEmprestimo` |
| Constante | UPPER_SNAKE_CASE | `MAX_EMPRESTIMOS` |
| Pacote | minúsculo | `br.unicap.biblioteca` |

Nomes devem comunicar a intenção do código.
