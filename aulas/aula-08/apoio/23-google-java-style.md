# Boas práticas de estilo

A aula apresenta o Google Java Style Guide como referência.

Práticas importantes:

- nomenclatura consistente;
- imports explícitos;
- indentação consistente;
- classes e métodos bem nomeados;
- evitar linhas excessivamente longas;
- organização clara do código.

O estilo não substitui a modelagem, mas torna o modelo mais legível e profissional.
