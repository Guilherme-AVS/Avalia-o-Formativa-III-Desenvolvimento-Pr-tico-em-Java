# Objeto

Objeto é uma instância de uma classe.

```text
Classe: Livro
        ↓
Objetos:
- Clean Code
- Java: Como Programar
- Design Patterns
```

Objetos possuem:

- identidade;
- estado;
- comportamento.

Do ponto de vista do código, uma variável pode referenciar um objeto criado a partir de uma classe.
