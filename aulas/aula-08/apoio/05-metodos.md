# Métodos

Métodos representam comportamentos.

```java
public void emprestar() {
    emprestado = true;
}
```

Um método pode:

- não retornar valor (`void`);
- retornar um valor;
- receber parâmetros;
- alterar o estado do objeto;
- consultar o estado do objeto.

A escolha do método deve refletir a responsabilidade da classe.
