# Do problema real ao modelo de classes

A modelagem parte de um enunciado e segue uma sequência:

1. entender o problema;
2. identificar entidades relevantes;
3. definir responsabilidades;
4. identificar atributos;
5. identificar métodos;
6. mapear relacionamentos;
7. representar o modelo em UML;
8. implementar o modelo em Java.

A pergunta central é:

> **Quem é responsável por quê?**

Procure substantivos para levantar candidatos a classes e verbos para levantar comportamentos.
