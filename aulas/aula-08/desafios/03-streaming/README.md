# Desafio 03 — App de Streaming

Modele uma plataforma com:

- `Usuario`;
- `Playlist`;
- `Musica`.

Requisitos:

- usuário pode criar várias playlists;
- playlist contém várias músicas;
- uma música pode aparecer em múltiplas playlists.

Além do UML, implemente:

- criação de playlist;
- adição de música;
- remoção de música;
- duração total da playlist.
