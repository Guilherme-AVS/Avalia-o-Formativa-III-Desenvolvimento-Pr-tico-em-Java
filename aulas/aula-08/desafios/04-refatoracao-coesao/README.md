# Desafio 04 — Refatoração por Coesão

Você recebeu uma classe fictícia `SistemaAcademia` com:

- cadastro de aluno;
- cadastro de plano;
- envio de e-mail;
- geração de relatório;
- cálculo de mensalidade;
- autenticação.

Analise as responsabilidades e proponha uma divisão em classes.

Para cada nova classe:

- defina propósito;
- atributos;
- métodos;
- dependências necessárias.

Depois, explique como a solução reduz acoplamento e aumenta coesão.
