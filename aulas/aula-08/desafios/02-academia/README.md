# Desafio 02 — Sistema de Academia

Uma academia deseja gerenciar alunos, planos e instrutores.

## Requisitos

- cada aluno possui um plano ativo;
- cada aluno pode estar vinculado a um instrutor;
- um instrutor pode acompanhar vários alunos.

## Tarefas

1. identificar classes;
2. definir pelo menos 3 atributos por classe;
3. definir pelo menos 2 métodos relevantes;
4. indicar getters/setters;
5. identificar 1:1 e 1:N;
6. construir UML;
7. implementar uma versão Java.

A apresentação da aula fornece uma possível modelagem, mas outras soluções justificadas podem ser válidas.
