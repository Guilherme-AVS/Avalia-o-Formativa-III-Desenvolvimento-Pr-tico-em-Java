# Desafio 01 — Sistema de Biblioteca

## Problema

Uma biblioteca precisa controlar acervo, usuários e empréstimos.

## Requisitos

### Acervo
- cadastrar livros;
- consultar livros;
- atualizar informações.

### Usuários
- cadastrar usuários;
- consultar histórico de empréstimos.

### Empréstimos
- registrar empréstimo;
- devolver livro;
- verificar disponibilidade.

## Entrega

1. identificação das classes;
2. atributos;
3. métodos;
4. relacionamentos;
5. multiplicidades;
6. diagrama UML;
7. implementação inicial em Java.

**Domínio condutor da aula.**
