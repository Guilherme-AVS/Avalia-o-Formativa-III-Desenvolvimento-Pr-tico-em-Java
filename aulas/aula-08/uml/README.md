# Diagramas UML — Aula 08

A sequência dos diagramas acompanha a progressão pedagógica:

1. uma classe;
2. duas classes;
3. associação 1:1;
4. associação 1:N;
5. agregação;
6. composição;
7. dependência;
8. sistema de biblioteca integrado;
9. sistema de academia.

Todos os arquivos são editáveis no Draw.io/diagrams.net.

A aula utiliza UML para tornar explícita a passagem:

```text
problema → classes → atributos/métodos → relacionamentos → Java
```
