# Exemplos — Aula 02

Os exemplos acompanham a progressão do conteúdo apresentado no material oficial.

| Arquivo | Conceitos |
|---|---|
| `TiposPrimitivos.java` | tipos primitivos |
| `TiposNaoPrimitivos.java` | `String`, arrays e classes |
| `VariaveisEConstantes.java` | declaração, inicialização, atribuição e `final` |
| `EscopoLocal.java` | escopo de variáveis locais |
| `OperadoresAritmeticos.java` | `+`, `-`, `*`, `/`, `%` e divisão inteira |
| `OperadoresRelacionaisEString.java` | comparações e `equals()` |
| `OperadoresLogicos.java` | `&&`, `||`, `!` |
| `IncrementoEDecremento.java` | pré e pós-incremento/decremento |
| `AtribuicaoCompostaEPrecedencia.java` | atribuição composta e precedência |
| `EntradaDados.java` | `Scanner`, `print`, `println`, `printf` |
| `DesafioEncontreOsErros.java` | versão corrigida do desafio da aula |
