# Checklist — Aula 02

## Tipos de dados

- [ ] Sei diferenciar tipo primitivo e não-primitivo.
- [ ] Sei reconhecer `byte`, `short`, `int`, `long`.
- [ ] Sei reconhecer `float`, `double`, `char` e `boolean`.
- [ ] Sei explicar por que `String` é um tipo não-primitivo.
- [ ] Sei declarar um array.

## Variáveis e constantes

- [ ] Sei declarar uma variável.
- [ ] Sei inicializar uma variável.
- [ ] Sei fazer uma atribuição posterior.
- [ ] Uso nomes descritivos em `camelCase`.
- [ ] Sei explicar escopo local.
- [ ] Sei declarar uma constante com `final`.

## Operadores

- [ ] Sei usar `+`, `-`, `*`, `/` e `%`.
- [ ] Sei prever uma divisão inteira.
- [ ] Sei usar `==`, `!=`, `>`, `<`, `>=` e `<=`.
- [ ] Sei comparar `String` usando `equals()`.
- [ ] Sei usar `&&`, `||` e `!`.
- [ ] Sei diferenciar pré e pós-incremento.
- [ ] Sei usar `+=`, `-=`, `*=`, `/=` e `%=`.

## Expressões e entrada/saída

- [ ] Sei aplicar precedência de operadores.
- [ ] Sei quando usar parênteses.
- [ ] Sei usar `print`, `println` e `printf`.
- [ ] Sei ler `String`, `int` e `double` com `Scanner`.

## Integração

- [ ] Consigo escrever um programa pequeno usando variáveis e operadores.
- [ ] Consigo explicar por que um código com tipos incompatíveis não compila.
