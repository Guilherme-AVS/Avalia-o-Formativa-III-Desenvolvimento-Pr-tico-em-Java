# Comandos de Terminal — Aula 02

Entre na pasta do exemplo:

```bash
cd exemplos/aula02
```

Compile:

```bash
javac TiposPrimitivos.java
```

Execute:

```bash
java TiposPrimitivos
```

Para um arquivo que usa `Scanner`:

```bash
javac EntradaDados.java
java EntradaDados
```

Para compilar vários arquivos independentes de uma pasta:

```bash
javac *.java
```

Para apagar os `.class` gerados no macOS/Linux:

```bash
rm -f *.class
```

## Observação

Os arquivos `.class` são produtos da compilação e não fazem parte deste pacote didático.
