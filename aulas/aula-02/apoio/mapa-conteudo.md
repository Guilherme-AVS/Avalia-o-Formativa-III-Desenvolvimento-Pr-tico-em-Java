# Mapa de Conteúdo — Aula 02

```text
Dados
├── Primitivos
│   ├── inteiros
│   ├── decimais
│   ├── char
│   └── boolean
└── Não-primitivos
    ├── String
    ├── arrays
    └── classes

Variáveis
├── declaração
├── inicialização
├── atribuição
├── nomenclatura
└── escopo

Constantes
└── final

Operadores
├── aritméticos
├── relacionais
├── lógicos
├── ++ e --
├── atribuição composta
└── precedência

Entrada/Saída
├── print
├── println
├── printf
└── Scanner
```

## Progressão pedagógica

A sequência central da aula é:

**informação → tipo → variável → expressão → operador → resultado → entrada/saída**

Essa base será reutilizada na Aula 03 para construir condições.
