# Tabela de Referência — Tipos e Operadores

## Tipos primitivos

| Tipo | Categoria | Exemplo |
|---|---|---|
| `byte` | inteiro | `byte idade = 20;` |
| `short` | inteiro | `short ano = 2026;` |
| `int` | inteiro | `int pontos = 100;` |
| `long` | inteiro | `long populacao = 200000000L;` |
| `float` | decimal | `float nota = 8.5f;` |
| `double` | decimal | `double salario = 3500.50;` |
| `char` | caractere | `char inicial = 'I';` |
| `boolean` | lógico | `boolean ativo = true;` |

## Operadores

| Grupo | Operadores |
|---|---|
| Aritméticos | `+ - * / %` |
| Relacionais | `== != > < >= <=` |
| Lógicos | `&& || !` |
| Incremento/decremento | `++ --` |
| Atribuição composta | `+= -= *= /= %=` |

## Precedência apresentada na aula

1. `()`
2. `++`, `--`, `!`
3. `*`, `/`, `%`
4. `+`, `-`
5. `<`, `<=`, `>`, `>=`
6. `==`, `!=`
7. `&&`
8. `||`
9. atribuições
