# Glossário — Aula 02

| Termo | Significado |
|---|---|
| Tipo primitivo | Tipo que representa valores simples da linguagem. |
| Tipo não-primitivo | Tipo baseado em referências a objetos, como `String`, arrays e classes. |
| Variável | Espaço associado a um tipo que pode armazenar um valor. |
| Declaração | Definição do tipo e nome de uma variável. |
| Inicialização | Atribuição do primeiro valor à variável. |
| Atribuição | Alteração do valor armazenado por uma variável. |
| Escopo | Região do código na qual uma variável pode ser acessada. |
| Constante | Valor que não deve ser alterado depois de inicializado, declarado com `final`. |
| Operador | Símbolo que representa uma operação sobre valores ou expressões. |
| Operador relacional | Operador que compara valores e produz `boolean`. |
| Operador lógico | Operador que combina ou nega expressões booleanas. |
| Precedência | Regra que determina a ordem de avaliação dos operadores. |
| Scanner | Classe de `java.util` usada para leitura de dados. |
| Divisão inteira | Divisão entre inteiros cujo resultado é inteiro. |
| Literal | Valor escrito diretamente no código, como `42`, `3.14` ou `"Java"`. |
