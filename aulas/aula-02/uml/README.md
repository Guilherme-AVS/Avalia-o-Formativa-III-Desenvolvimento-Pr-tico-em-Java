# Diagramas — Aula 02

Os diagramas desta pasta são editáveis em **Draw.io / diagrams.net**.

## Diagramas

1. `tipos-de-dados.drawio` — classificação entre tipos primitivos e não-primitivos;
2. `ciclo-variavel.drawio` — declaração, inicialização, atribuição, uso e escopo;
3. `operadores.drawio` — famílias de operadores apresentadas na aula;
4. `precedencia.drawio` — ordem de precedência apresentada no material;
5. `entrada-saida.drawio` — relação entre `Scanner`, variáveis e saída no console.

## Papel pedagógico

Os diagramas não substituem os exemplos Java. Eles funcionam como mapa visual para conectar:

**conceito → sintaxe → expressão → comportamento do programa**.
