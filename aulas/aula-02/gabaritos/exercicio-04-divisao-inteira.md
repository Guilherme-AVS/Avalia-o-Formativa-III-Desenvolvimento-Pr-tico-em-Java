# Gabarito — Exercício 04

```java
int a = 7 / 2;       // 3
double b = 7 / 2;    // 3.0
double c = 7.0 / 2;  // 3.5
int d = 7 % 2;       // 1
```

Em `7 / 2`, os dois operandos são inteiros. A divisão é realizada como divisão inteira antes da atribuição a `double`. Para obter `3.5`, pelo menos um dos operandos deve ser decimal.
