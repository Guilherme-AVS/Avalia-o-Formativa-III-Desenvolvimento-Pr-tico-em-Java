# Gabarito — Exercício 09

```java
int a = 5 + 3 * 2;       // 11
int b = (5 + 3) * 2;     // 16
int c = 20 / 5 + 2 * 3;  // 10
boolean d = 10 > 5 && 4 < 2 || 3 == 3; // true
```

Em `a`, a multiplicação ocorre antes da adição.

Em `b`, os parênteses alteram a ordem.

Em `c`, divisão e multiplicação têm precedência sobre a adição.

Em `d`, as comparações são avaliadas antes de `&&`, e `&&` antes de `||`.
