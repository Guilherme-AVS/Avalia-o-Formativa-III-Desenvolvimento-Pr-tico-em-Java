# Exercício 06 — Operadores Lógicos

Considere:

```java
int idade = 21;
boolean possuiIngresso = true;
boolean documentoValido = true;
```

Crie uma expressão `podeEntrar` que seja verdadeira somente quando a pessoa tiver idade mínima de 18 anos, ingresso e documento válido.

Crie também `precisaAcompanhante`, considerando que a pessoa precisa de acompanhante quando tiver menos de 18 anos ou não possuir documento válido.
