# Contribuindo com o repositório

Este repositório é acadêmico e institucional. Alterações devem preservar a organização da disciplina.

## Regras

1. Não mover ou renomear avaliações sem autorização da professora.
2. Não publicar gabaritos em locais destinados aos estudantes quando a atividade ainda estiver em aplicação.
3. Manter cada aula no padrão `aulas/aula-XX/`.
4. Preferir nomes de arquivos em `kebab-case` e sem espaços.
5. Diagramas UML editáveis devem ser mantidos em `.puml`.
6. Código Java deve compilar na versão Java adotada pela atividade.
7. Evitar dependências externas desnecessárias nos exemplos didáticos.

## Estrutura de uma aula

```text
aula-XX/
├── README.md
├── slides/
├── exemplos/
├── exercicios/
├── gabaritos/
├── uml/
└── apoio/
```
